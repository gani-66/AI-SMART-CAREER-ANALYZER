# AI Smart Career Analyzer

An AI-powered platform that helps students analyze their resumes, prepare for interviews, and improve their career readiness through intelligent feedback.

## 🚀 Features

- Resume upload and analysis
- Resume scoring and feedback
- Skill-based interview question generation
- AI-powered interview preparation
- Interview answer evaluation
- Final performance results
- User authentication
- Career preparation assistance

## 🛠️ Technology Stack

### Frontend

### Backend

- FastAPI

### Database
- MongoDB

### AI Integration
- Google Gemini API

### Tools
- Visual Studio Code
- Git
- GitHub

## 🔄 Project Workflow

1. User logs into the application.
2. User uploads or enters resume information.
3. The system analyzes the resume and evaluates skills.
4. AI generates interview questions based on the user's skills.
5. User answers the interview questions.
6. The system evaluates the answers.
7. The final results and improvement suggestions are displayed.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/gani-66/AI-SMART-CAREER-ANALYZER.git
cd AI-SMART-CAREER-ANALYZER
```

### 2. Backend Setup

```bash
cd backend
pip install -r requirements.txt
```

Configure your environment variables in a local `.env` file.

### 3. Frontend Setup

```bash
cd frontend
npm install
npm start
```

## 🔐 Environment Variables

Create a local `.env` file and add your required API keys.

**Never upload API keys or passwords to GitHub.**
